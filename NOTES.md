# NOTES

## Studio setup (2026-11-22)
- Remotion 4.0.545 (blank template, TypeScript). Compositions: `Test` (5 s, src/videos/Test).
- Browser: Remotion's own download (remotion.media) is blocked here. `remotion.config.ts` auto-uses the
  pre-installed Chrome headless shell found by `tools/find_browser`; CLI renders can also pass
  `--browser-executable="$(tools/find_browser)"`.
- Fonts: Poppins 700/800 in public/fonts, loaded by `src/lib/fonts.ts` (FontFace + delayRender/continueRender).
  Call `loadPoppins()` at the top of every video file. `outline()` gives the thick dark text stroke.
- Timing helpers: `src/lib/words.ts` (`wordFrame`, `lineFrame`, `durationFromVoice`).
- Whisper: model host `openaipublic.azureedge.net` is blocked -> `tools/word_times.py` falls back to
  silencedetect LINE times (no word times). Allow that host under Network access to get word times.
  Models are stored in ./models (git-ignored).

## Pipeline
1. Voice arrives in `voice/`. `tools/clean_voice voice/ep1.wav` -> `public/voice/ep1.wav`
   (pauses > 0.3 s cut to 0.15 s, 1.1x speed same pitch, -16 LUFS).
2. `python3 tools/word_times.py public/voice/ep1.wav --lang hi` -> `public/words.json`
   (fallback: add `--script script.txt` with one spoken line per row to label the lines; tune `--min-pause`).
3. Build `src/videos/<name>/`, register in `src/Root.tsx`.
4. QC: `tools/stills <Comp> @word1 @word2 ... (12 stills) --out out/<name>_sheet.png`
   (frames as numbers, `1.5s`, or `@word` / `@word#2` from words.json).
5. Render: `npx remotion render <Comp> out/<name>.mp4`
6. `python3 tools/make_watermark.py @handle` once, then `tools/finish out/<name>.mp4`
   -> `out/<name>_final.mp4` (-14 LUFS, TP <= -1.5, watermark 30%).

## Sound pack (generated by `python3 tools/make_sfx.py`, no downloads)
public/sfx: whoosh pop ding tick click thud splash sparkle buzzer slam (48 kHz WAV, peaks about -1 dBFS;
use at volume 0.1-0.3). public/music/loop.wav: 8 s, 120 BPM, seamless loop, peak -6 dBFS.

## Known limits
- `tools/finish` reaches -14 LUFS on normal voice+music mixes (tested: -14.1 LUFS, TP -1.8). A clip that is
  almost silent (e.g. the Test reel: one pop) cannot reach -14 within the true-peak limit; it stops at about -15.4.
- `tools/clean_voice` lands within about 0.5 LU of -16 (tested: -16.5) because loudnorm respects the -1.5 dB true peak.
- pip installed the CUDA build of torch (~5 GB); the CPU-only index (download.pytorch.org) is blocked here.
